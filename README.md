    # Udemy Clone

A simple **Udemy Clone** website built using **HTML5** and **CSS3**. This project recreates the basic layout and design of the Udemy homepage.

## ✨ Features

- Responsive Navigation Bar
- Hero Section
- Course Categories
- Featured Courses
- Footer
- Responsive Design

## 🛠 Technologies Used

- HTML5
- CSS3
- Google Fonts
- Font Awesome

## 🎯 Purpose

This project was created to improve my HTML and CSS skills by building a responsive website.

> **Note:** This project is for educational purposes only.
